这期讲的是 AI 基础设施需求为什么从 GPU 外溢到 CPU。Agent 运行时需要 CPU 调度工具、处理数据、执行代码和编排流程；上下文窗口变长后，KV Cache 膨胀也会把更多数据卸载到 SSD 并交给 CPU 处理。结果是数据中心 CPU/GPU 配比从过去的 1:4 或 1:8，提升到 1:1 或 1:2，服务器 CPU 开始出现价格上涨和交付周期拉长。

供给侧的问题是先进制程、ABF 载板和 T-Glass 等封装材料都被 AI 芯片需求挤压。AMD 受益于 EPYC 需求但受制于台积电产能，英特尔加速 18A 良率和产能控制，英伟达推出 Vera CPU，Arm 也开始亲自做 AGI CPU。核心判断是 CPU 不再只是 AI 配角，而重新变成数据中心系统吞吐的关键瓶颈。
