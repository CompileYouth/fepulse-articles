Peter Yang 这期和 Moritz Kremb 拆解怎样把 Claude Code 搭成个人 chief of staff。Moritz 的 Claude OS 不是一个单点提示词，而是一组 folder structure、skills、MCP、CLI、memory 文件和自动化任务的集合。每次接入新工具，他会让系统更新 `tools.md`，再通过长期记忆和每日记忆把工作状态压缩保存下来。

访谈先比较 OpenClaw 和 Claude Code：OpenClaw 的优势是移动端和聊天应用接入、heartbeat、cron jobs、子 agent 更自然；Claude Code 的优势是编码能力、dispatch、routines 和托管 managed agents 正在补齐。Moritz 的核心思路是先搭一套稳定骨架，再一个工具一个工具接入，而不是一开始追求万能 agent。

最值得借鉴的是它对个人操作系统的定义：不是让 AI 替你聊天，而是让它持续维护记忆、检查 todo、触发周期任务、连接购物/邮件/文件等工具，逐渐变成一个可扩展的个人工作层。这条适合后续整理成“个人 agent OS 怎么搭”的实操型详读。
