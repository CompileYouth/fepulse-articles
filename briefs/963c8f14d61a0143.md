这期 Lightcone 讲 Garry Tan 重新开始写代码的过程。背景是他已经多年主要做投资和 YC 管理工作，但最近几个月重新打开 Claude Code，连续写出大量代码，并把一些开源项目从零推到十万 GitHub star 级别。节目想回答的是：AI 编程工具到底怎样改变一个已经很久不写代码的 builder。

最有代表性的例子是 Gary's List。他把自己早年的 Posterous 博客系统第三次重写：第一次创业时花了数百万美元、多人团队和一年多；第二次 Posthaven 花了约十万美元和几个月；这次用 Claude Code Max 账号，成本大约 200 美元，五天做出完整博客平台，并叠加了 RAG、agentic retrieval、深度研究和自动生成长文的能力。

这条的价值不在“又一个人 vibe coding 成功”，而在它把软件形态也改了：Gary's List 不是给记者发布文章的 CMS，而是自己能做资料检索、论点整理、引用提取和长文生成的工作系统。访谈里那句比喻很准：现在用 AI 编程像开法拉利，很快、很刺激，但你最好也是机械师，因为它坏在路边时仍然要你自己修。
