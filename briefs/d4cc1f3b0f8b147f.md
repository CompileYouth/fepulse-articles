Every 在 Anthropic 的 Code with Claude 现场复盘了当天发布内容。最直接的信号是算力：Anthropic 和 xAI / SpaceX 的 Colossus 集群达成计算资源合作，缓解 Claude Code 用户过去明显感受到的额度和使用窗口限制。对重度用户来说，这不是边角更新，而是能不能把 Claude 当作日常工作系统来用的基础条件。

产品层面最值得盯的是 Claude managed agents。它加入了 memory、agent orchestration 和 outcome 等能力，目标不是让用户和一个本地助手聊天，而是让团队可以在云端配置长期运行、异步执行、可扩展的 agent。访谈里把这看成 OpenAI 与 Anthropic 战线变清楚的信号：一边是本机工作操作系统，比如 Claude Code 或 Codex；另一边是面向团队和生产环境的云端 agent 平台。

他们认为 Anthropic 在 agent orchestration 上暂时走得更靠前，原因是 Claude Code / Claude Work 里已经有 dispatch、多 agent 协作和 outcome 式任务抽象。现在 managed agents 把这些能力产品化，虽然看起来不像发布一个新模型那么刺激，但可能是接下来几个月真正重要的基础设施入口。
