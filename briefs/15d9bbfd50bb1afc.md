这条内容介绍的是一种被拿来和传统大语言模型对比的方向：EBM，也就是 energy-based model。视频想表达的关键不是“LLM 已经过时”，而是指出了 autoregressive 模型的一种根本限制：它必须一 token 一 token 往前生成，因此在生成过程中很难回头全局修正。视频用路线导航打比方，说这种模型就像每次只能选一个方向前进，哪怕前面有坑，也可能因为生成路径被锁死而继续走错。

EBM 被强调的优势，在于它不是按 token 序列逐步展开，而是可以对整体状态进行评分和搜索，因此更适合处理那些需要全局一致性、约束满足或整体结构优化的问题。视频的核心判断是：未来的 AI 栈不一定会只靠 LLM 一路扩展，某些 LLM 不擅长的任务，可能需要由完全不同的模型范式来补位。对普通使用者来说，这条内容最值得记住的是，AI 的下一波进展未必只是“更大的语言模型”，也可能是把不同类型的模型组合起来，去覆盖 LLM 本来就不擅长的那部分任务。
