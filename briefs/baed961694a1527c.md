tldraw 创始人 Steve Ruiz 讲的不是普通白板工具，而是“无限画布”作为一种基础交互层的价值。tldraw 最早只是一个开源绘图库，用来帮团队在 Web 里构建类似 Miro、Figma 的无限画布，但因为这个领域同时牵涉设计、性能、多人与复杂几何交互，很快吸引了 Figma、Adobe 和大量想做画布能力的团队。

真正有意思的部分在 AI 之后出现：很多适合多人协作的画布交互，也适合人与 agent 协作。Steve 描述过一个实验场景：15 个真人和 45 个空间化 agent 同时在同一张画布上工作，agent 会根据自己在画布上的位置获得局部上下文。这让白板不只是展示工具，而开始像一个可视化的 agent 工作空间。

他也谈到 tldraw 的商业边界：任何强工程团队理论上都能自己做一个画布，但很少有人会把底层交互、性能、API 和长期维护做到足够深。tldraw 卖的不是“能画图”的表层能力，而是一个已经沉淀了大量 UX 判断和工程细节的底座。在 AI 能快速复制软件的环境里，这类深层基础设施仍然有价值，因为 agent 更应该站在可靠底座上构建，而不是重新生成脆弱的底层。
