Ryan Wiggins 用一条很清楚的历史线索解释了“为什么企业接下来要为 Agent 设计产品”：银行过去先后经历了网点、ATM、网站、移动 App 几个阶段，而下一个阶段很可能就是 API 和一组能被对话式界面调用的服务。也就是说，用户面前的交互层会不断变化，但真正需要稳定沉淀的是底层能力接口。

他后半段讲的“Claude Code second brain”更具体：把自己过去几年与业务表层相关的几百万字材料整理成知识库，再让它成为未来 Agent 调用的上下文底座。这个思路的价值不在于再做一个笔记仓库，而是在于把零散经验沉淀成可以被 AI 消费和复用的工作资产。对程序员和产品团队来说，这意味着下一步竞争力会越来越多地体现在上下文组织和接口设计上。
