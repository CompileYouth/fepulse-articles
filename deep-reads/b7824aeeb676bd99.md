这场对谈一开始，主持人先从 Amjad Masad 早年的经历问起，说他 23 岁来美国时背着信用卡债务、似乎也没有工作。Amjad 先纠正说，其实他当时已经拿到了 Codecademy 的 offer。主持人笑着说，那 technically 还是“还没正式上班”。随后主持人把话题切到一个很现实的问题：创业在最早期、甚至在“负一阶段”时，大家都说 persistence、resilience、grit 很重要，但顽强坚持和死抱一个并不好的想法之间，界线其实很细。Replit 走了将近九年才真正被市场广泛视为成功，公司是怎么撑过来的？

Amjad 说，如果从 Replit 算起，其实远不止九年。等他真正来到美国时，Replit 已经是一个开源 side project，前前后后加起来接近二十年。他接着讲了“信用卡债务”的故事。自己当时虽然拿到了 Codecademy 的工作机会，但根本没有钱来美国。离开约旦时，他拿的是 O-1 签证，当时那种签证还非常少见，机场工作人员甚至怀疑这是骗人的签证，非要他买一张回程机票，因为 O-1 不是移民签证。那张回程票几乎花掉了他所有的钱。到了纽约后，Codecademy 的创始人都还在硅谷融资，他这个第一位员工就自己待在纽约，身上几乎没钱。后来他用在约旦办的信用卡消费，以为它像借记卡一样，余额变负数还以为是“卡里多了钱”。结果欠到一两万美元，他父亲还打电话来说，约旦那边警察都在找他。后来这笔钱还是慢慢还清了。

讲完这个故事后，主持人把问题拉回来：究竟是什么让他一直做下去？Amjad 的回答是，当然存在一种可能，就是你只是疯了，死死抓着一个想法十几年也未必会成功，创业史上这样的例子很多。但真正推动他走下去的，不只是抽象的坚持，而是他持续看到 Replit 对现实用户有用。最开始是有人在 Replit 上学了一点编程，后来做出一个 iOS App，每个月在 App Store 赚到一千美元。再后来，这样的故事越来越多。到现在，他几乎每天都会听说某个用户在 Replit 上做到了百万美元收入，甚至有人已经做到八百万美元。这种反馈一直在提醒他：这不是一个自我感动式的想法，它真能改变一部分人的命运。

他还说，真正让团队兴奋的，不只是图表一直向右上角走，更是和用户交谈时感受到的那种能量。你做的东西在帮助人，而且帮助他们从“会一点技术”变成“真的做成生意”。这件事比单纯看收入数字更让他觉得值得。

接着主持人转向 Haya，问她当年为什么愿意加入 Replit。Haya 先回忆说，那时她自己是有工作的，而 Amjad 还在当学生。他来找她帮忙设计 Replit 的 logo 和界面。她甚至不知道 “read-eval-print loop” 是什么意思，只能一边问他一边想象，于是把它理解成水面上的 ripple，做出了最早的 logo。后来她还给产品做了 UI，Amjad 当时先改掉了很多东西，最后又兜回来用了她最初做的那套。她拿这件事打趣说，这就是设计师和工程师的经典关系：工程师总觉得自己更懂，但最后又会回到设计师最早那版。

再往后，主持人把话题直接切进 AI，说现在好像出现了“本地开发复兴”的叙事，而 Replit 做的恰恰是云端、从 prompt 到 deploy 的沙盒系统。作为一直在做云原生开发环境的团队，他们怎么看这种变化？Amjad 的回答是，要区分绝对量和市场占比。他认为所有类型的开发都在增长，不论是本地还是云端，但本地开发有一些根本性的限制。为了说明这一点，他举了一个刚发生的 JavaScript 供应链攻击事件：某个非常流行的请求库被投毒，如果安装了那个版本，攻击者几乎可以接管你的电脑。

他说，在 Replit 里，这类风险会小很多。因为环境是在云端，不直接连到你的本地机器；而且他们会阻止 post-install scripts，限制刚发布不久的包，还设置最低包龄。即便漏洞几小时后就被发现，这几小时里也已经有几百万人装了有问题的包。Amjad 说，潮流和 hype 总会变化。Replit Agent 在 2024 年 9 月上线时几乎是市场上唯一的 agent 产品之一，而现在整个行业都在做类似东西。他们对此其实很自豪，因为这意味着他们确实推动了一轮变化。下一步，他们还会去做一些真正新的东西。

他还提到，企业业务现在增长很快，核心原因恰恰是安全和可靠性。很多企业不希望员工在本地装一堆 agent、OpenClaw 之类的东西，而是更愿意使用一个长期被验证过的云环境。主持人接话说，自己也觉得“本地开发回潮”有点不合逻辑，因为云环境更安全、更容易自动扩缩容，也更适合现代工作流。

然后，主持人抛出了另一个更宏观的问题：作为创始人，现在最令人不安的事之一就是变化速度太快。Replit 一边建立在大模型和更高层抽象之上，一边又不断被这些基础能力“吞进去”，好像平台在往上长、你做的东西也可能被平台自己吸收。那么 Replit 是怎么理解这场竞速的？

Amjad 说，他要讲两件彼此矛盾的话。第一件是，作为创始人，日常执行时必须近乎“愚蠢地专注”。每天关心的问题应该非常局部：公司有没有增长、有没有新客户、产品卖得怎么样。如果出问题，就直接去问客户。客户会告诉你是不是竞争太激烈、是不是某个功能不行、是不是别的地方卡住了。你必须在局部、在日常层面把这些问题一个个解决掉。很多时候，最好的做法就是把外界噪音关掉，只盯住自己的用户。

但与此同时，第二件事又完全相反：创始人必须时不时抬头，认真预测未来的方向，并思考公司在那个未来里要站在哪里。Amjad 说，他其实觉得“预测未来”没有大家想象得那么难。比如他在 2023 年的一场 AI 演讲里，就公开说过软件开发会在接下来几年里发生怎样的变化，甚至描述了后来所谓 vibe coding 的很多元素。今天回头看，那张路线图里很多节点已经实现了，比如并行 agent 等能力。他说，这说明公司仍然需要一些深层判断，基于这些判断做未来六到十二个月的关键押注。但这些判断不应该吞没每天的执行，否则你会什么都做不出来。

主持人回应说，这可能正是今天创始人最难学的一种“矛盾能力”：既要有非常稳固的北极星和哲学判断，又要在日常中不过度被各种新风向牵着走，同时也不能完全拒绝外界的有效信息。Amjad 说，是的，这件事本身就很难。

接下来主持人问，既然他们已经完成了 2023 年那张路线图的一大部分，那么接下来三年会是什么。他开玩笑说，Amjad 不一定愿意在台上全说出来。Amjad 最后只透露了一点：他觉得他们正走向一个 post-prompting world。这里的意思不是 prompt 会消失，而是现在这种“你打一段 prompt，系统回一段结果”的模式已经接近顶点。下一阶段的核心会有两个方向：第一是新的 AI 交互界面，第二是真正可以在后台持续工作、能 push 也能 pull、能理解你和你的组织、并主动做有用工作的全自动 agent。

主持人问，界面难道最终不还是网页吗？Amjad 说，随着模型的多模态能力提升，人和机器之间的交互会越来越自然。你可以面对屏幕说话、打开摄像头、用手势操作，像在对一个真正的协作者讲话，而不是不断敲 prompt。他提到 Replit 新推出的 canvas 界面，说你可以直接对着画布说“把这个挪过去”“把那个收短一点”“让布局更紧凑”，那种感觉更像在和系统共同工作，而不是在给它写指令。主持人补充说，这甚至有点像电影《钢铁侠》或《少数派报告》里的交互方式。

Amjad 说，除了新界面，更重要的是让 agent 能真正理解你。现在用户经常会不断重复：“我不是这个意思”“你忘了上次我们讨论过的背景”“你应该理解我的偏好”。而未来的系统应该逐渐知道你的习惯、你的 taste、你做多个项目时一贯的方式。在 Replit Agent 4 里，他们已经在往这个方向推：整个项目上下文集中在一个地方，同一个空间里可以同时看到 Web、移动端、后端，甚至可以直接让系统基于整个项目上下文生成一套给投资人看的 slide deck。Amjad 说，这些界面之所以值得做，是因为大模型公司本身更多在追求模型能力的上限，而没有把全部精力放在用户体验整合上，这就给创业者留下了巨大的空白地带。

最后他举了一个令他印象很深的真实例子：自己做肩部手术后认识了一位物理治疗师，对方一直想做一个系统，能够记录病人的身体状态、扫描动作、在家指导训练。Amjad 说，这类人过去很难真的把想法做成软件，但现在他们越来越有机会。对他来说，这也再次说明，Replit 想推动的并不是“更多人学会传统意义上的写代码”，而是让更多人有能力把一个现实问题做成一个产品，再把这个产品做成一门生意。
