视频一开始，作者先说明这是一条对 Claude Design 的上手实测。他会现场跑五个 demo，分别用这个工具做视频、幻灯片、网站、App，最后再试一个 design system。接着他先抛出自己的总体判断：Anthropic 现在已经不只是做一个模型公司，而是在把整套知识工作栈重新做一遍。开发有 Claude Code，设计有 Claude Design，文档侧还有 co-work 一类的产品。它们背后有一个共同前提，就是代码正在变成知识工作的通用媒介。视频、幻灯片、网站、App、动画，这些东西本质上都能被表示成代码，而代码现在已经变得很便宜了。

他说，正因为这样，Anthropic 实际上已经开始直接和 Figma、Google Workspace、Microsoft Office 以及一批 AI 原生工具竞争。然后他把问题收回来：Claude Design 到底做得怎么样，值不值得认真看。

第一个 demo 是做动画视频。作者进入 Claude Design 之后先新建一个项目，然后去找 Anthropic 官方发布 Claude Design 的那篇公告，把整段内容复制进来，直接下指令，让它基于这段内容做一个动画视频。提交之后，系统没有立刻开始生成，而是像 Claude Code 一样先追问一串澄清问题，比如视频要多长、语气是什么、重点覆盖什么、视觉方向怎么选、这个视频是拿来做什么的、过渡风格希望是什么样、要不要展示产品界面、最后怎么收尾。

作者故意在这些问题里大量使用“你替我决定”。他的目的不是精细地控制输出，而是想看这个系统有没有基本的产品和设计判断。然后他继续让系统生成。几分钟后，成片出来了。他切到展示模式播放，先看到一张标题页，文案是 “the speed of thought”，接着是几个使用场景的切换，还有带动画的插图，最后是一段 call to action。作者边看边点评，认为最厉害的地方不是“做出来了”，而是这件事过去通常要视频编辑花几个小时甚至几天，现在几分钟就搭出来了。

他同时也指出一个目前明显的缺点：在他测试时，Claude Design 似乎还不能很方便地把结果直接导出成视频文件，所以你如果真的要拿走成片，还得靠录屏之类的方式。但即便如此，他仍然觉得这个 demo 很有说服力，因为它说明视频这种设计产物已经不再只是后期软件里的一个工程，而是可以从文字和简单设定直接生成的代码产物。

第二个 demo 是做幻灯片。这里作者先交代了自己的工作流：如果要让 AI 做一套 deck，他不会直接把零散想法丢进去，而是先用普通 Claude 把每一页的文案和结构来回打磨，最后拿到一份比较清晰的 slide copy。然后他把这份 copy 整段贴进 Claude Design，让它直接生成一套 slide deck。

第一版结果是一个静态的 deck，能看，但作者觉得比较呆板，和前面视频里的表现力差距很大。于是他给出自己的“pro tip”：不要一上来就让 Claude Design 生成静态幻灯片，而是先让它按同样的内容做一个动画视频，然后再把这个视频转成一个可手动翻页的动画 deck。为此，他复制前一个项目，几乎只加了一句提示：把这个视频转换成一个可以手动切换的演示文稿。这样出来的结果明显更有动感，也更接近他真正想要的效果。

这里他还顺手演示了人工微调。他先手动删掉了一处自己不喜欢的文字，又让系统把几个模块的位置调换，最后再开 tweak 面板去改色板。作者的看法是，像这类 AI 设计工具可以非常快地帮你完成前 90%，但最后 10% 往往还是需要人工调整。也就是说，AI 足以把初稿成本打到很低，但如果你要把成品做得更顺，还需要保留一些手工介入的空间。

后面一个有意思的尝试是 landing page。作者直接让 Claude Design “重做 Claude co-work 的官网页面”，提示语其实很偷懒，甚至连链接都没认真给，但系统还是自己找到了页面并做出一个大约 80% 像的版本。作者一边往下滚一边指出，页面里当然还有不少问题，比如视频区域没复现出来，一些细节也没对上，但整体风格和结构已经很接近了。

接着他玩了一个更轻松的变体：在保留这个页面风格的基础上，把文案改成一个戏谑版的“Anthropic 接管所有知识工作”。新版本的标题和副文案都变得很夸张，类似“Anthropic 已经收购了工作本身”“请放心把职业交给我们”这种口吻。作者觉得这一段挺有意思，因为它说明 Claude Design 不只是做视觉复刻，还可以沿着同一套页面结构，快速替换文案语气、创意方向和具体表达。

再往下，他展示了几个更偏视觉实验的例子。一个是让 Claude Design 做一个深色主题的 3D 地球，用来表现文化如何在城市之间流动。生成出来的结果已经有旋转效果和控制项，但大陆形状还不太对，看起来像糊成了一整块。另一个例子是做一个超大可编辑文本框，让某些词在输入时带出相应的粒子效果，比如输入 fire 会出现火焰，输入 smoke 会出现烟雾，输入 electric 会出现电的视觉效果。作者现场打字演示这些词是怎么触发不同效果的，基本想表达的是：只要你愿意试，Claude Design 已经能很快把一些互动视觉点子做出来。

接着进入移动 App。作者让 Claude Design 设计一款健身应用，系统同样先问了一串问题，比如使用场景是力量训练还是别的、用户是严肃运动员还是忙碌上班族、视觉风格、是否要单一版本、交互程度怎么选等等。作者继续大量使用“你来决定”。几分钟后系统生成出一套暖色调的健身 App 界面，有首页、训练页和一些交互状态。作者能点进去看 bench press、权重调整、记录组数之类的东西。

他这里注意到两个点。第一，整体观感已经相当像样。第二，界面里还是会有一些明显问题，比如文字重叠之类的小 bug。但有意思的是，Claude Design 自己会在后台继续截图、检查、修复，也就是说 Anthropic 似乎把某种“play testing”内建进去了。它不是停在第一次输出，而是会继续自我检查。这让作者觉得它至少在工作方式上，已经不像一个单纯出图工具，而更像一个会继续自己 debug 的系统。

最后一个 demo 是 design system。作者先承认自己不是专业设计师，也不太懂 design system，但还是拿苹果 liquid glass 的一套 Figma UI kit 去喂给 Claude Design，让它直接生成一个 Apple liquid glass 风格的设计系统。这个过程花了大概十分钟，消耗也很大。他的建议是，除非你真的很想尝试，不然不要随便拿最重的任务来烧 token。

系统生成出来的东西包括字体、颜色、间距、图标、动效曲线、圆角、阴影等模块。作者并没有认真逐项审查，而是一路点 “looks good”。然后他又拿刚才那套 design system 去生成同一个健身 App 的液态玻璃版本。结果看起来风格上确实更接近 liquid glass，但问题也更多，比如元素重叠、整体完成度不如前一个没有套 design system 的版本。作者最后给出的解释也很直接：一方面可能是这个任务本来就更难，另一方面也是因为他给的设计系统本身并不算精细。

视频最后，他把自己的结论总结成几条。第一，Anthropic 明显在尝试做整套知识工作栈，不只是模型或一个点状工具。第二，传统工具如 Figma、Office 这一类，原本是按“人一页页手工做出来”设计的，而新的默认路径已经变成“先和 AI 一起做到 90%，再自己补最后 10%”。第三，像 Replit、Lovable、Gamma 这样的 AI 原生产品和 Claude Design、Claude Code 之间的边界开始变得很模糊，他已经有点看不清 Anthropic 究竟是想做平台，还是会逐步和所有 AI 创业产品正面竞争。

最后他把话题收回到个人创作者和个人 builder 身上。他觉得现在最大的利好，是一个人终于第一次有机会在设计和工程上都得到 AI 的基础支持。只要你本来就有产品感和想法，AI 已经足以充当一个入门级设计师和入门级工程师。Claude Design 当然还很早，还有不少 bug，和 Claude Code、co-work 的关系也还没完全理顺，但它已经是一种非常值得上手尝试的新产品形态，因为整个过程本身就非常有意思。
